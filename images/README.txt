Сюда можно положить настоящие фотографии товаров.

Имя файла = id товара + расширение: 1.jpg, 2.jpg, ... 42.jpg (подходят также .png и .webp).
Дополнительные фото для галереи на странице товара: 1-2.jpg, 1-3.jpg ... (до 6 штук на товар).
Если файл есть, сайт покажет фото; если нет — реалистичную иллюстрацию из images.js.
Лучше всего подходят снимки с пропорциями 4:3 на однотонном фоне.
После добавления файла обновите страницу — перезапуск сервера не нужен.
